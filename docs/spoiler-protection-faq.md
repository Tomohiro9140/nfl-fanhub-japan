# ネタバレ防止：利用者向けFAQと注意事項

## 標準動作

ネタバレ防止をONにすると、選択チームの **公式キックオフ時刻以後** に公開されたLATEST NEWS記事は表示しない。したがって、試合前の記事は表示され、試合中・試合終了直後・後日の結果記事は隠れる。比較にはUTCの時刻だけを使い、表示時だけ日本時間（JST）へ変換する。

## よくある質問

| 質問 | 回答 |
|---|---|
| 試合開始直前の記事は見られますか？ | はい。キックオフより前に公開された記事は表示されます。 |
| 試合中の記事は表示されますか？ | いいえ。試合中に試合経過やスコアが含まれる可能性があるため、標準で隠します。 |
| FINAL後の記事は表示されますか？ | いいえ。試合後の記事も同じく隠します。 |
| ネタバレ防止をOFFにするとどうなりますか？ | LATEST NEWSの通常選択に戻り、記事を公開日時順に表示します。 |
| 試合日で判断していますか？ | いいえ。日付ではなく、公式キックオフの正確なUTC時刻で判断します。 |

## 注意事項

> ネタバレ防止はサイト内のスコア表示とLATEST NEWSを対象にした機能であり、外部リンク先のページ、ブラウザ通知、検索結果、SNS、動画サムネイルまでは制御できない。

LIVE試合で公式キックオフ時刻が一時的に未取得の場合は、時刻を推測して一部記事を表示するのではなく、安全側としてLATEST NEWSを一時的に全件隠す。公式日程・スコアボードの更新後に正しい時刻で再判定する。また、ユーザーがネタバレ防止をOFFにした場合は、表示記事の見出しや要約に試合結果が含まれる可能性がある。
